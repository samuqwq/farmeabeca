# 🚀 FarmeaBeca

**Plataforma educativa gamificada de apoyo estudiantil**  
Inspirada en el Ministerio de Educación de Chile (Mineduc)

---

## 📋 Descripción

FarmeaBeca es una plataforma web **full frontend** que permite a estudiantes y colegios interactuar de forma gamificada. Incluye misiones, pares mentores, apoyo psicológico y un sistema de puntos (FBP).

Todo funciona 100% offline con `localStorage`.

---

## ✨ Características Principales

- **Dos roles**: Alumno y Colegio
- Validación completa de **RUT chileno**
- Dashboard juvenil para alumnos y profesional para colegios
- Sistema de **misiones dinámicas** (administrables por el colegio)
- Pares Mentores
- Chat psicológico estilo WhatsApp
- Sistema de suscripción (Básico / Premium)
- Gestión completa de misiones por parte del colegio
- Diseño moderno, responsive y mobile-first

---

## 🛠️ Tecnologías

- HTML5 semántico
- Bootstrap 5.3 (CDN)
- CSS3 moderno + variables
- JavaScript Vanilla modular
- `localStorage` para persistencia

---

## 🚀 Cómo usar

1. Abre el archivo **`index.html`** en tu navegador.
2. Regístrate como alumno o colegio.
3. ¡Listo! Todo funciona sin servidor.

**Datos de prueba:**
- RUT ejemplo: `12345678-5`
- Cualquier contraseña sirve en login (demo)
